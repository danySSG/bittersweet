# SPEC v0.12 — «Человеческий режим»: история, пульт вкуса, квиз

Фидбек основателя: обсерватория «красивая, но технарская; хочется больше интерактива
и больше для ламеров». Принцип волны: та же математика — но наружу идентичность,
рассказ и игра, а не оси и перцентили. Язык — тёплый, вторая персона, с юмором,
БЕЗ жаргона (запрещённые слова в пользовательском тексте: перцентиль, кластер, PCA,
энтропия, KDE, стандартизация; вместо них: «настроение», «твоя стая», «главная ось»,
«сколько в тебе личностей»).

## A. Backend: генератор истории

- `GET /api/p/{id}/story` — ленивый одноразовый (как observatory): собирает
  СТРУКТУРИРОВАННУЮ историю из payload (portrait + observatory + timeline, если есть):
  `{chapters: [{id, emoji, title, paragraphs: [str], interactive: {...}|null}]}`.
- Генератор: `app/engine/story.py` — детерминированные шаблоны на русском с
  подстановками и ветвлениями по данным. Главы (пропускаются, если данных нет):
  1. `identity` («Кто ты»): топ-архетип + доля + энтропия по-человечески
     («в тебе уживаются ~4 музыкальные личности, но главная — 🍬 биттерсвит: каждый
     третий трек»). interactive: {kind: "archetype_chips", data: доли архетипов}.
  2. `sound` («Как звучит твой вкус»): темп/яркость/минор через сравнения-якоря
     (темп — с пульсом: «~118 ударов в минуту — как сердце на быстрой прогулке»;
     яркость: «тёплый и приглушённый, как лампа, а не как люминесцентная контора»).
     interactive: {kind: "play_track", data: highlights.most_yours (label, videoId,
     preview_url)} — «вот трек, который звучит как ты весь сразу».
  3. `home_key` («Твой музыкальный дом»): топ-тональность колеса по-человечески
     («ля-минор — самая частая тональность у тебя; в ней написаны …» + 2 примера
     из библиотеки в этой тональности с ▶).
  4. `rare_birds` («Твои странности»): 2-3 верхних outlier'а с человеческим why
     («самый странный гость — {label}: {why}. Как он к тебе попал?»).
     interactive: {kind: "play_list", data: топ-3 ворон}.
  5. `story_of_time` («Как ты менялся») — ТОЛЬКО если есть timeline: 2-3 самых
     резких перелома (максимальные |дельты| minor/bittersweet между соседними
     бакетами): «в {период} тебя качнуло в тёмное: минор с N% до M%».
     interactive: {kind: "timeline_mini"}.
  6. `clock` — ТОЛЬКО если observatory.clock: «грустное ты лайкаешь ночью: пик — {окно}».
  7. `finale`: «что дальше» — CTA-глава: слушать радио архетипа / копнуть точку / квиз.
- Числа в тексте округлять по-человечески («каждый третий», «почти половина»,
  «двое из десяти») — хелпер share_to_phrase(share) с тестами на границы.
- Тон: дружелюбный, слегка ироничный, НИКОГДА не оценивающий негативно
  («странности» — с любовью). 1-3 коротких абзаца на главу, не простыни.
- Тесты: главы пропускаются без данных; share_to_phrase; запрещённый жаргон
  отсутствует в сгенерированном тексте (регекс-тест по списку запрещённых слов);
  идемпотентность (payload-кэш story_version=1); 409 для старых портретов.

## B. Frontend: режим «История»

- На странице портрета сверху — переключатель вида: **«История» | «Портрет»**
  (для новых зрителей пермалинка дефолт — «История», для владельца после анализа —
  «Портрет»; выбор запоминать в localStorage).
- Вид «История»: вертикальный скроллителлинг: главы появляются с мягким fade/slide
  при доскролле (IntersectionObserver, prefers-reduced-motion → без анимаций);
  эмодзи-буллеты глав; интерактивы:
  - archetype_chips: чипы долей, клик — подсветка соответствующих точек на мини-карте;
  - play_track / play_list: карточки с ▶ (use-audio, режимы превью/полный как везде);
  - timeline_mini: компактный существующий график.
- Финальная глава — три больших CTA-кнопки (радио / пульт / квиз).
- Вид «Портрет» — всё как сейчас; секция «Обсерватория» переименовывается в
  «Под капотом» и сворачивается по умолчанию (details).

## C. Frontend: «Пульт вкуса»

- Компонент taste-console на странице портрета (в «Истории» — глава-CTA, в «Портрете» —
  секция над discovery): два крупных слайдера-оси: «грустнее ↔ веселее» (valence 0..100)
  и «тише ↔ мощнее» (energy 0..100), большой курсор-«пятно» на мини-карте синхронно.
- Логика: при отпускании ползунка (и раз в ~700мс при драге) — ближайший к точке трек
  библиотеки С preview_url (клиентский поиск по points; исключать последние 3 сыгранных,
  чтобы не залипало) → мгновенно играет превью + карточка «{label} · {meta}» + пульс
  точки на мини-карте.
- Кнопка «копнуть здесь» → существующий point-discovery с текущими координатами.
- Мобайл: слайдеры широкие, touch-friendly.

## D. Frontend: квиз «Угадай себя»

- Кнопка «🎯 Угадай себя» на портрете → модальный/встроенный квиз, 5 вопросов,
  генерируются клиентски из portrait+observatory (данные уже загружены):
  1. «Какой из этих треков у тебя САМЫЙ быстрый?» — highlights.fastest + 2 случайных
     не-хайлайта (детерминированный PRNG от portrait_id);
  2. «Кто из этих троих — твоя „белая ворона“?» — outliers[0] + 2 типичных
     (максимальная typicality);
  3. «Какая тональность — твой дом?» — топ колеса + 2 других из колеса;
  4. «Какое настроение у тебя главное?» — топ-архетип + 2 других (по эмодзи+имени);
  5. «Сколько треков в твоём портрете?» — n_tracks ±разумные дистракторы.
- После ответа: раскрытие с правильным ответом, короткая подпись и ▶ где уместно;
  в конце счёт «N/5» + фраза (5 — «ты знаешь себя как свои пять плейлистов», 0-1 —
  «твой вкус загадочнее, чем ты думал») + кнопка «поделиться результатом»
  (копирует текст «Я угадал N/5 фактов о своём вкусе — bittersweet»).
- Все варианты кликабельны с ▶ ДО ответа (честно: слушай и решай).

## E. Definition of Done

1. pytest зелёный: главы/пропуски, share_to_phrase, регекс-тест на жаргон, 409,
   идемпотентность; без сети.
2. Живой smoke: GET /api/p/hulxfwmp/story → главы identity/sound/home_key/rare_birds
   (+finale), текст без запрещённых слов, повторный GET мгновенный.
3. Фронт: NEXT_BUILD_DIR=.next-build сборка; tsc; живые серверы не трогать.
4. Браузер: /p/hulxfwmp — переключатель «История|Портрет», главы анимируются,
   ▶ в главах играет, пульт двигается и играет ближайший трек, квиз проходится
   до счёта, «Обсерватория» стала свёрнутым «Под капотом»; консоль чистая.
5. Прежнее не сломано: вся сюита, дискавери/радио/обсерватория живы.
