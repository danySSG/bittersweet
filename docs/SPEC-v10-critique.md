# SPEC v0.10 — ответ на критику основателя: настоящая динамика, галактика 2.0, полные треки

Критика (16.07): эволюция скучная и без динамики «за всё время»; галактика кубическая;
вращение мешает читать hero-текст; треки играют только 30-сек превью.

## A. Настоящая динамика вкуса — по датам ЛАЙКОВ (backend + frontend)

### Backend

- Источники несут временную метку трека:
  - youtube: playlistItems.snippet.publishedAt (дата добавления в LL = дата лайка) →
    Track.liked_at (ISO); уже запрошенный part=snippet это содержит — без новых квот;
  - takeout: колонка timestamp плейлистного CSV → liked_at;
  - плейлист-ссылка: Playlist Video Creation Timestamp из ytmusicapi, если есть; иначе null.
- liked_at протаскивается через pipeline в DataFrame и в points[].liked_at (ISO, nullable).
- `build_portrait`: если >=60% точек имеют liked_at и они покрывают >=3 календарных
  месяца — строить `timeline`: бакеты по месяцам; соседние бакеты с <8 треками сливать
  (адаптивно до кварталов/полугодий); на бакет: {period_start, period_end, n_tracks,
  tempo_median, minor_share, bittersweet_share, top_archetype{name,emoji}}.
  timeline кладётся в payload портрета (аддитивно).
- Тесты: liked_at сквозь конвейер; слияние мелких бакетов; отсутствие timeline при
  <3 месяцах покрытия; порядок бакетов.

### Frontend (/portraits и страница портрета)

- Главный блок «Динамика вкуса за всё время»: берётся НОВЕЙШИЙ портрет с timeline
  (обычно «лайки YouTube»); SVG-график по реальной оси времени (месяцы/годы):
  линии minor_share и bittersweet_share (%), пунктиром tempo (нормированный, правая ось);
  над бакетами — эмодзи топ-архетипа периода; ховер бакета — тултип с цифрами.
  Дельта-чипы: первый период vs последний («за N лет: минор −8 пп, темп +15 bpm…»).
- Старый график «по портретам» ПОНИЗИТЬ: свернуть в details «динамика по портретам»,
  фильтровать к одному источнику (только лайки/Takeout; демо и плейлисты исключить),
  показывать только если >=3 точек на >=3 разных днях. Иначе скрыт.
- На странице портрета (если есть timeline) — компактная версия графика под картой.

## B. Галактика 2.0 (frontend, components/galaxy-view.tsx)

- Сферизация: каждую ось из перцентиля p (0..1) прогонять через probit
  (обратная CDF нормали; аппроксимация Аклама или rational approx — БЕЗ зависимостей),
  результат клиппить в ±2.5σ и нормировать → гауссово облако вместо куба.
- Атмосфера: (1) радиальный градиент-свечение в центре сцены (слабое, фиолетовое);
  (2) глубинный туман — дальние точки бледнее и меньше (уже есть — усилить кривую);
  (3) 2-3 десятка микро-«пылинок» (полупрозрачные крошечные точки со случайным дрейфом,
  seed фиксированный от id портрета — БЕЗ Math.random в рендер-цикле).
- Оси-подписи оставить (они смысловые), но приглушить.

## C. Hero-лендинг: галактика не мешает тексту (frontend)

- Галактика: opacity вниз (~0.3), вращение вдвое медленнее, центр смещён вправо от
  текстовой колонки (offset по x).
- Текстовый блок получает радиальную виньетку-подложку (тёмный scrim с blur-краем),
  чтобы контраст текста был железный при любом положении звёзд.
- prefers-reduced-motion: статичный кадр (уже есть — сохранить).

## D. Полные треки через официальный YouTube-плеер (frontend + чуть backend)

### Backend (мелочь)

- В `highlights[]` и `discoveries[]` уже есть/добавить `videoId` (у хайлайтов сейчас
  нет — добавить из df). examples_rich — тоже + videoId. Тесты контракта обновить.

### Frontend

- Мини-плеер получает переключатель режима: «Превью 30с» (как сейчас) / «Полностью».
- Режим «Полностью»: официальный YouTube IFrame Player API (script с youtube.com,
  загружать лениво при первом включении режима): в мини-плеере видимое окошко плеера
  ~120×68 (требование YouTube — плеер видим; НЕ прятать в display:none), очередь через
  loadVideoById, автопереход по onStateChange ENDED; onError → пропуск трека
  (бейдж «недоступен во встраивании») с фолбэком на превью, если есть.
- Кнопки ▶ на строках уважают текущий режим. Бейдж «полная версия · YouTube» в плеере.
- Треки без videoId в режиме «Полностью» пропускаются (или играют превью с пометкой).

   читаем, мини-плеер переключает режимы (YT-iframe появляется), старый график свёрнут
   в details.
5. Прежнее не сломано: вся сюита, /portrait?demo=1, discovery/radio на превью.
