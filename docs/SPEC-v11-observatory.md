# SPEC v0.11 — «Обсерватория»: аналитический этаж портрета

Мандат основателя: «больше визуализаций, больше анализа, больше математических моделей!!!»

Принцип: обсерватория считается ИЗ СОХРАНЁННОГО ПОРТРЕТА (points[].features уже там) —
работает на старых портретах без пересчёта аудио. Бэкенд считает модели и отдаёт
ГОТОВЫЕ К ОТРИСОВКЕ данные; фронт только рисует (SVG, без чарт-библиотек).

## A. Backend: GET /api/p/{id}/observatory

- Ленивая одноразовая сборка: при первом запросе считает всё ниже, кладёт в payload
  портрета под ключ `observatory` (+`observatory_version: 1`), отдаёт; повторные —
  из payload. Портрет без features в points → 409 «портрет старой версии».
- Модели (sklearn/numpy уже в зависимостях; НОВЫХ пакетов НЕ добавлять):

1. `key_wheel`: кварто-квинтовый порядок [C,G,D,A,E,B,F#,C#,G#,D#,A#,F];
   counts мажор/минор по 12 позициям + доля каждого; топ-тональность.
2. `ridgelines`: для tempo, brightness, minor_score, bittersweet — KDE (гауссово ядро,
   Silverman bandwidth, 64 точки сетки, диапазон p1..p99); отдать {grid[], density[],
   median, p25, p75} на каждый признак (density нормировать к максимуму 1).
3. `radar`: 7 MOOD_FEATURES — перцентиль медианы портрета ОТНОСИТЕЛЬНО всех сохранённых
   портретов базы (fingerprint-статистики list_portraits; если портретов <5 — относительно
   демо-набора). {axes: [{name_ru, self_pct, avg_pct=50}]}.
4. `pca`: sklearn PCA на стандартизованных MOOD_FEATURES: 2 компоненты;
   {explained: [v1, v2] (%), axes: [{loadings: {feat: w}, label_pos, label_neg}]},
   где label_pos/neg — человеческая интерпретация из топ-3 |loadings|
   (словарь feat→рус: tempo «быстрее», minor_score «минорнее», brightness «ярче»,
   bittersweet «биттерсвитнее», percussive «ритмичнее», energy_rms «плотнее»,
   onset_rate «дробнее»; отрицательные — антонимы «медленнее/мажорнее/тёмнее/…»);
   coords точек НЕ нужны (биплот рисуется по loadings + существующим points).
5. `tsne`: sklearn TSNE (2D, perplexity=min(30, max(5, n//4)), random_state=42,
   init="pca") на стандартизованных MOOD_FEATURES; координаты нормировать в 0..100;
   отдать {x, y} ПО ИНДЕКСАМ points (той же длины и порядка, чтобы фронт взял
   цвета/лейблы/videoId из points). n>600 — подвыборка не нужна (наши <=500).
6. `outliers`: IsolationForest(contamination=0.05, random_state=42) на тех же данных;
   топ-8 по аномальности: {label, videoId, score 0..100 (нормированный ранг),
   why: топ-2 признака с максимальным |z|, по-русски: «экстремально быстрый (222 bpm)»}.
7. `clock`: если liked_at есть у >=50 точек: 24 часовых бакета и 7 дней недели:
   {hour_counts[24], hour_bittersweet[24] (доля, null если <3 треков в часе),
   weekday_counts[7], weekday_bittersweet[7], peak_hour, insight: строка вида
   «биттерсвит чаще всего ты лайкаешь в HH—HH+2» (максимум скользящего окна 3ч,
   только если в окне >=10 треков)}. Иначе clock: null.
8. `entropy`: Шеннон по долям кластеров (в битах, log2) + effective_moods = 2^H
   (округлить до 0.1) + фраза-вердикт: <1.5 «монолитный вкус», <2.2 «сфокусированный»,
   иначе «многоликий».

- Тесты (без сети, синтетические DataFrame/payload): каждая модель — форма и инварианты
  (KDE нормирован, суммы колеса = n, PCA explained убывает, tsne длина/диапазон,
  outliers <=8 и why непусто, clock null при <50, энтропия против ручного расчёта
  на равных долях = log2(k)), «старый портрет» → 409, идемпотентность (второй GET
  не пересчитывает — проверить по маркеру в payload).

## B. Frontend: секция «Обсерватория» на странице портрета

- После блока биттерсвит — секция-заголовок «ОБСЕРВАТОРИЯ» с ленивой загрузкой
  (fetch observatory при доскролле/раскрытии; спиннер; 409 → подсказка «перестрой
  портрет»; старый бэк 404 → секция скрыта молча).
- Сетка панелей (2 колонки desktop, 1 mobile), все SVG руками, палитра бренда,
  tabular-nums, тултипы:
  1. Колесо тональностей: 12 секторов по кругу квинт, внешнее кольцо мажор/внутреннее
     минор, высота = count, ховер: «A minor · 24 трека»; топ-тональность подписью.
  2. Риджлайны: 4 профиля друг под другом со сдвигом (joyplot), медиана — точка,
     p25-p75 — подсветка; подписи диапазонов человеческие.
  3. Радар: 7-угольник, твой контур (заливка фиолет 30%) поверх пунктирного среднего;
     подписи осей по-русски.
  4. PCA-биплот: стрелки признаков по loadings первой пары компонент, подписи
     label_pos/label_neg на концах осей, «ось 1 · N% вкуса» / «ось 2 · M%»;
     точки — те же points, спроецированные ФРОНТОМ по loadings (стандартизация
     по своим точкам) — лёгкая линейная алгебра на клиенте.
  5. Режим карты «Форма»: сегмент-контрол Карта | Галактика | Форма; «Форма» — те же
     точки на tsne-координатах (цвета кластеров, тултипы, клик-точка → как на карте
     НЕ обязателен в этой волне — только просмотр); плавная анимация перехода
     координат Карта→Форма приветствуется, но опциональна.
  6. Белые вороны: список с score-бейджем, why-подписью и ▶ (превью/полный режим
     как везде через use-audio).
  7. Часы вкуса: полярные 24-часовые «лепестки» (высота=count, цвет=доля биттерсвита
     от синего к розовому), рядом 7 столбиков дней недели; insight-строка под ними.
     clock null → панель скрыта.
  8. Тайл энтропии: крупное число «H бит», подпись «≈ N настроений», вердикт.
- В /portraits карточках НИЧЕГО не менять (обсерватория — только на странице портрета).
