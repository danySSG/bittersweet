# music-taste — карта твоего музыкального вкуса

Ночной проект: взять сохранённую музыку из YouTube Music и найти **измеримый
отпечаток** того, что тебя цепляет — «ритмичное, быстрое, меланхоличное».

## Идея одним абзацем

Каждый трек можно разложить на числа: темп, лад (мажор/минор), «ударность»,
энергию, яркость тембра. Если посчитать это для всей твоей библиотеки и
разложить на карте **энергия × настроение**, видно, где кучкуется твой вкус.
Твоя зона — правый… то есть **высокая энергия + низкое настроение**
(«грустный бэнгер»): тело хочет двигаться, а сердце грустит.

## Конвейер

```
fetch_tracks.py  →  data/tracks.json     список треков из YT Music
analyze_audio.py →  data/features.csv     темп/лад/энергия (скачивает фрагменты)
build_map.py     →  data/map.html + taste.csv   карта вкуса и отпечаток
recommend.py     →  (дальше) новые треки в твою зону
```

## Как запустить

Всё через `uv` (окружение уже собрано на Python 3.12).

### 1. Достать треки

**Вариант А — публичный/скрытый плейлист (без логина, проще всего):**
```bash
uv run fetch_tracks.py --playlist "https://music.youtube.com/playlist?list=PL..."
```

**Вариант Б — твои лайки (нужна разовая авторизация):**
```bash
uv run auth_setup.py          # инструкция внутри; вставить заголовки из браузера
uv run fetch_tracks.py --liked
```

### 2. Проанализировать
```bash
uv run analyze_audio.py --limit 30   # проба на 30 треках
uv run analyze_audio.py              # вся библиотека (можно прерывать, есть кэш)
```

### 3. Построить карту
```bash
uv run build_map.py
open data/map.html
```

## Признаки и что они значат

| признак      | что это                                 | связь со вкусом       |
|--------------|-----------------------------------------|-----------------------|
| `tempo`      | темп, BPM                               | «быстрое»             |
| `key`/`mode` | тональность и лад (major/minor)         | «меланхоличное» = минор |
| `minor_score`| уверенность, что это минор (0..1)       | сила меланхолии       |
| `percussive` | доля ударной энергии                    | «ритмичное / драйв»   |
| `energy_rms` | громкость/плотность                     | энергия               |
| `brightness` | спектральный центроид (Гц)              | светлый/тёмный тембр  |
| `onset_rate` | атак в секунду                          | дробность/суета       |

## Приватность

`auth/` (куки/сессия YouTube) и `data/`, `audio/` — в `.gitignore`.
**Никогда не коммить и не пересылай папку `auth/`** — там доступ к твоему аккаунту.

## Оговорки

- Темп librosa иногда определяет вдвое больше/меньше реального — на массе не мешает.
- Лад на плотном искажённом звуке (метал, шумные жанры) определяется шумно.
- `valence` (настроение) — эвристика из мажорности и яркости, не абсолют.
  Смысл в относительном расположении *внутри твоей* библиотеки.
