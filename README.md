# Bittersweet 🍬 — акустический портрет музыкального вкуса

> **Статус: заморожен (30 июля 2026).** Продукт функционально готов (v0.14, 336 тестов,
> Dockerfile, runbook деплоя), но не задеплоен. Репозиторий сохранён, чтобы не потерять
> прогресс. Возобновить можно с [docs/DEPLOY.md](docs/DEPLOY.md).

Сервис, который **анализирует реальный звук** твоих любимых треков (а не жанровые теги)
и превращает его в портрет вкуса: настроения-архетипы, карту/галактику, «биографию вкуса»
по датам лайков — и находит новую музыку в выбранном настроении.

Родился 7 июля 2026 из ночного вопроса «мне нравится ритмичная быстрая меланхоличная
музыка — что с этим можно сделать?». Ответ оказался термином **биттерсвит** — он и стал именем.

## Что умеет

- **Входы:** «Войти через YouTube» (официальный OAuth, только чтение лайков), ссылка на
  плейлист YouTube Music, выгрузка Google Takeout, демо без логина.
- **Анализ звука** по 30-сек превью из открытых каталогов (Deezer/iTunes): темп
  (перцептивный, без октавных ошибок), лад и «биттерсвит» (грань мажор/минор), яркость,
  энергия, ритмичность — librosa, только дескрипторы, аудио не хранится.
- **Портрет:** архетипы («грустный бэнгер» 🌒, «биттерсвит» 🍬, «тихая грусть» 🌫️…),
  2D-карта / сферическая 3D-галактика / t-SNE-«Форма», «самые-самые», хайлайты с ▶.
- **Человеческий режим:** «История» (рассказ о вкусе словами), «Пульт вкуса» (ползунки
  с мгновенным звуком), квиз «Угадай себя»; техника — в свёрнутом «Под капотом»
  (колесо тональностей, KDE, радар, PCA, белые вороны, часы вкуса, энтропия).
- **Discovery:** «Найти ещё такого» по архетипу и **по клику в любую точку карты**,
  радио с полными треками через YouTube-плеер.
- **Динамика:** биография вкуса по датам лайков за годы; часы/дни недели.
- **Соц-слой:** постоянные ссылки, share-card 1080×1920, сравнение вкусов двух людей.
- **Надёжность:** джобы переживают рестарт сервера, single-flight, честное «проанализировано
  N из M», 30-дневная политика хранения данных YouTube API.

## Структура

```
service/backend/    FastAPI + librosa + SQLite · uv · 336 тестов · Dockerfile
service/frontend/   Next.js 15 · рукописный SVG/canvas, без чарт-библиотек
docs/               ARCHITECTURE.md, SPEC-*.md (14 волн), ANALYSIS-AUDIT.md, DEPLOY.md
*.py (корень)       исходный ночной эксперимент: анализ 448 лайков, кластеры, discovery
data/features_full.csv   демо-набор (379 треков) для режима без логина
```

## Быстрый старт

```bash
cd service/backend && cp .env.example .env && uv sync && uv run uvicorn app.main:app
cd service/frontend && npm install && npm run dev      # → http://localhost:3000
```

Демо работает сразу; вход через YouTube требует GOOGLE_* в `.env` (см. `service/backend/README.md`).

## Ключевые архитектурные решения

См. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Кратко: Spotify API мёртв для новых
продуктов (2026) → мульти-источник; аудио — только легальные превью, храним только
дескрипторы; дифференциатор — единственный B2C с реальным акустическим анализом.
Известные ограничения анализа честно перечислены в [docs/ANALYSIS-AUDIT.md](docs/ANALYSIS-AUDIT.md).

## Приватность

`.env`, `auth/`, `cache.db`, HAR-выгрузки — в `.gitignore`. В репозитории нет секретов;
демо-CSV содержит только названия/артистов треков и акустические признаки.
